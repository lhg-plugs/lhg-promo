# lhg-promo-goal：促销目标与档期策略

> 目标：促销开始前，先回答"为谁、为什么、赚不赚钱"。
> 核心纪律：**目标不量化不开工；档期不排好不设计玩法。**

## 1. 何时使用

- 用户说"搞个促销""做个活动"但说不清要什么 → 从第 2 步开始问
- 已有目标但只有定性描述（"提升销量""冲一波"）→ 做第 3 步量化
- 档期已定但没检查过冲突 → 直接看第 4 步
- 复盘时目标对不上 → 回看第 5 步"目标卡"模板

## 2. 输入与输出

**输入**：用户的一句话诉求（如"双11想清仓""新店开业拉新"）、历史经营数字（客单价/转化率/流量，有最好，没有就标假设）。

**输出**：《目标卡》一页纸，包含：主目标（单选）/ 量化指标 / 利润底线 / 时间窗口 / 目标人群。目标卡是后续所有步骤的"宪法"，玩法、测算、执行都不得违背它。

## 3. 分步方法论

### 第 1 步：主目标三选一（单选，不过多选）

一次促销只能有一个主目标。多目标等于没目标，资源会内耗：

| 主目标 | 本质 | 成功标准示例 |
|---|---|---|
| 清仓 | 把库存变成现金，利润让路 | 尾货清仓率 ≥80%，回款 ≥X 万 |
| 拉新 | 花钱买用户，短期利润让路 | 新增下单用户 ≥X 人，获客成本 ≤Y 元 |
| 冲 GMV | 规模优先，为排名/声量/现金流 | 活动 GMV ≥X 万，订单量 ≥Y 单 |

**判断技巧**：问用户"如果只能实现一个，你选哪个"。追问"为什么是现在做"——清仓看库存周转天数，拉新看自然流见顶，冲 GMV 看现金流缺口。原因不同，玩法完全不同。

### 第 2 步：目标量化（定性目标打回重写）

把"提升销量"翻译成数字三件套：**规模指标**（GMV/订单量/清仓件数）+ **效率指标**（转化率/客单价）+ **约束指标**（利润底线/最大亏损额）。

- 规模指标看野心，效率指标看健康度，约束指标是红线。
- 约束指标必须用户亲口说："最多能亏多少"或"最少要赚多少"。用户说"尽量不亏"→ 翻译成"亏损上限 0 元"，写进目标卡。
- 数字要有依据：参考去年同期、日常均值×系数。拍脑袋的数字也要写，但标注"拍脑袋"，复盘时重点检讨。

### 第 3 步：目标人群一句话

"25-35 岁女性白领"这种颗粒度就够了，不需要长篇画像。作用只有一个：后面写玩法和宣传语时，能代入这个人读一遍——她看得懂规则吗？她会被打动吗？

### 第 4 步：排档期（四项检查）

1. **撞车检查**：是否落在 618（6.1~6.20）、双11（11.1~11.15）、双12、年货节窗口？撞了只有两个选项：错峰，或明确写出"蹭大促"的打法（比如做大促承接页、差异化品类）。"应该没事吧"不算选项。
2. **预热检查**：预热期 ≥3 天。预热做三件事：蓄水（加购/收藏/预约）、种草（内容预热）、测试（小流量验证玩法无 bug）。
3. **时长检查**：常规促销 3~10 天。超过 14 天用户疲劳、价格体系受损；不足 2 天来不及发酵。
4. **人力检查**：档期含节假日 → 必须有值班表；大促档期 → 必须有备货盘点计划。

输出《档期表》：预热期 / 正式期 / 返场期（可选）起止日期。

### 第 5 步：输出目标卡（模板）

```markdown
## 促销目标卡
- 主目标：（清仓/拉新/冲 GMV 三选一）
- 量化指标：规模__ 效率__ 约束（利润底线）__
- 时间窗口：__至__
- 目标人群：一句话__
- 数字依据：（历史数据/拍脑袋，注明）
```

目标卡经用户确认后锁定。后续任何"顺便加个玩法""力度再大点"的请求，先对照目标卡：违背主目标或击穿利润底线 → 驳回。

### 目标冲突调解话术（用户坚持多目标时）

用户说"三个都要"时，不要直接说"不行"，用选择题替他做减法：

1. "如果清仓率 80% 但只拉新 500 人，你能接受吗？"→ 测出他真正的排序。
2. "预算只够支撑一个主玩法的投流，你投给哪个？"→ 用资源约束逼单选。
3. 实在都要 → 拆成两个活动：A 活动清仓（直降）、B 活动拉新（拼团），档期错开。**一个活动一个主目标，两个活动各干各的。**

### 目标卡评审会（15 分钟）

目标卡写完后，花 15 分钟和用户（或团队）过一遍，只问四个问题：

1. 主目标如果实现了，算不算成功？（检验目标是否抓住了真诉求）
2. 利润底线是真底线吗？击穿了谁负责？（检验约束是否有效）
3. 数字依据是什么？拍脑袋的部分标出来了吗？（检验诚实度）
4. 时间窗口内人力/预算够吗？（检验可行性）

四个都答得上来 → 锁定目标卡，进入玩法设计。答不上来 → 回去重写，不许带着疑问开工。

## 4. 反模式

- **目标缝合怪**："既要清仓又要拉新还要冲 GMV"——三个目标对应三种玩法，缝在一起哪个都做不好。对策：排优先级，其他两个降为"顺带观察指标"。
- **档期拍脑袋**："就下周吧"——不查撞车、不留预热。对策：第 4 步四项检查一项项过。
- **约束指标缺失**："先做看看"——没有利润底线，测算环节失去刹车。对策：逼用户说出数字，说不出来就按"亏损上限 0"写。
- **目标卡锁抽屉**：写完没人看，执行时随意加码。对策：每次加需求先问"目标卡上写了吗"。

### 目标卡变更管理（锁定后想改怎么办）

目标卡锁定后，变更走"变更单"流程，不许口头改：

1. 谁提的变更、改什么、为什么改，写三行说清楚。
2. 评估影响：玩法要重做吗？测算要重算吗？档期要重排吗？
3. 用户（或负责人）签字确认，变更单存档。

**经验**：活动前 3 天内的目标变更，90% 是拍脑袋。变更单的作用不是阻止变更，是让拍脑袋的成本显性化——看到"要重做玩法+重算+重排档期"，很多人就冷静了。

### 附：目标卡填写示例

```markdown
## 促销目标卡（示例：秋季清仓）
- 主目标：清仓
- 量化指标：规模=清仓 5000 件尾货、回款 30 万；效率=转化率 ≥2.5%；
  约束=整体亏损上限 2 万元（尾货减值已计提）
- 时间窗口：2026-10-20 至 2026-10-27
- 目标人群：25-35 岁女性白领，价格敏感型老客为主
- 数字依据：库存 5200 件（系统数据）；客单价 80（近 30 天均值）；
  转化率 2.5%（去年同期清仓活动数据）
```

**填表检查**：每个数字后面都能答出"哪来的"。答不出的标"拍脑袋"，拍脑袋超过 3 个 → 目标卡打回，先去找数据。

> 小提示：目标卡建议打印出来贴在工位上。活动期间任何"加个玩法""力度大点"的要求，
> 先指着目标卡问一句："主目标和利润底线还保得住吗？"——90% 的临时加码到这就停了。

## 5. 自检与反馈

**质检门**（用本 skill 产出目标卡后自查）：

- [ ] 主目标是单选，不是多选
- [ ] 三个量化指标（规模/效率/约束）都有数字
- [ ] 利润底线是用户亲口确认的数字
- [ ] 档期四项检查全部通过（撞车/预热/时长/人力）
- [ ] 目标人群能一句话说清

**标准冒烟用例**：输入"下个月想搞个促销清仓"，应输出包含三选一提问、量化追问、档期四项检查的目标卡，而不是直接给玩法。

**反馈**：发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-promo/issues，正文写清"复现步骤 → 实际表现 → 期望表现"。
